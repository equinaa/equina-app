# Equina MVP QA Scenarios

## Core App

- Home tab loads as a global equestrian dashboard.
- Search filters gear recommendations immediately.
- Filter chips update visible results.
- Gear tab can add a demo tack item.
- Selecting gear returns the user to Home with a visible status update.
- Stable tab displays horse profile and care context.
- AI tab shows confidence labels and safety disclaimers.
- Community tab displays seeded coach and gear-context posts.

## AI Safety

- Session summary never diagnoses illness.
- Health-risk language recommends vet review.
- Saddle fit output shows low confidence without measurements.
- Brand-specific recommendation is blocked unless structured source data exists.

## Gear Trust

- High-value saddle requires verified seller status when resale is used.
- Saddle listing is rejected when any required angle is missing.
- Helmet listing is blocked when impact history is true.
- Support case requires evidence photos.
